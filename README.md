# EmployerManage

Application de gestion des congés du Ministère de l'Économie, des Finances et du Budget (République de Guinée).

Stack : Django + Django REST Framework (backend), React (frontend), PostgreSQL (base de données).

Voir [CLAUDE.md](CLAUDE.md) pour les règles de travail sur ce dépôt, et [docs/README.md](docs/README.md) pour la documentation du projet.

## Statut

En phase de cadrage. Le scaffolding du backend et du frontend n'est pas encore fait.
